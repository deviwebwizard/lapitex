## Image uploads

Admin-uploaded images are validated, auto-rotated, resized to a maximum 2000px dimension, and converted to lossy WebP at quality 84 before storage. Only the resulting image URL/path is saved in the database.

For production on Railway, configure a Cloudinary unsigned image upload preset using `CLOUDINARY_CLOUD_NAME` and `CLOUDINARY_UPLOAD_PRESET` (see `.env.example`). Configure that preset to allow only WebP images, cap uploads at 5 MB, and use a `lapitex` asset folder. Local development falls back to optimized files in `public/uploads`; production does not use the app filesystem because it is not durable across deployments.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
